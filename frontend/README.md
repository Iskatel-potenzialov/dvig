# Цифровой механик — демонстрационный фронтенд

React, TypeScript и Vite. Из папки `frontend` в PowerShell:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, показанный Vite (по умолчанию `http://127.0.0.1:5173/`). Проверки: `npm.cmd run build`, `node --test tests/demo.cjs`.

Автомобили и диагностические проверки читаются из синтетического `../neurodvs_hackathon_mock/data/vehicles.json`; один чат и черновик на автомобиль сохраняются в localStorage конкретного браузера. Очистка данных браузера или другой браузер не сохраняют историю: серверного постоянного хранилища пока нет. Ответы на сообщения явно демонстрационные. PDF в примере карточки загружается из временной базы проекта; карточка помечена как пример, а не доказательство ответа.

Реальные RAG, ML API, сохранение чатов на сервере, история ремонта и отправка заявок в ТОиР не подключены. Одна запись истории ремонта — явно обозначенный демонстрационный пример. Форма заявки не отправляет данные. Интеграция и правила автозаполнения по PDF ожидают серверного контракта.
