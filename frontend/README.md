# Цифровой механик — демонстрационный фронтенд

React, TypeScript и Vite. Из папки `frontend` в PowerShell:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте адрес, показанный Vite (по умолчанию `http://127.0.0.1:5173/`). Проверки: `npm.cmd run build`, `node --test tests/demo.cjs`.

Автомобили и идентификаторы проверок читаются из синтетического `../neurodvs_hackathon_mock/data/vehicles.json`. Кнопка диагностики запрашивает следующую проверку по HTTP через `/ml-api/diagnose`, а не берёт результат из файла. Прогресс и полный ответ хранятся вместе с чатом автомобиля в localStorage; старые демонстрационные сообщения не считаются выполненными API-проверками. Очистка данных браузера или другой браузер не сохраняют историю: серверного постоянного хранилища пока нет. Ответы на сообщения явно демонстрационные. PDF в примере карточки загружается из временной базы проекта; карточка помечена как пример, а не доказательство ответа.

ML-заглушку необходимо запустить отдельно из `neurodvs_hackathon_mock`: `python -m uvicorn mock_ml.app:app --port 18371`. Этот порт выбран для проекта: порт 8001 может быть занят другим сервисом. При установленном другом адресе перед запуском Vite задайте `$env:ML_API_TARGET='http://127.0.0.1:8011'` и перезапустите Vite. Прокси Vite применяется к dev-серверу; production-хост должен предоставить аналогичный маршрут `/ml-api`. Тесты: `node --test tests/demo.cjs tests/ml.cjs`.

Реальные RAG, сохранение чатов на сервере, история ремонта и отправка заявок в ТОиР не подключены. Одна запись истории ремонта — явно обозначенный демонстрационный пример. Форма заявки не отправляет данные. Интеграция и правила автозаполнения по PDF ожидают серверного контракта.
